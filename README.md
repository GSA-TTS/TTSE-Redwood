# ttse-redwood

Repository for the TTSE Redwood Data Agent.

This repo is the application container for the Federal Data Exchange MVP described in [003-mvp-architecture.md](https://github.com/GSA-TTS/TTSE-Redwood/blob/main/docs/adr/003-mvp-aws-infrastructure-diagram.md).

## Current scope

The repository currently provides an MVP foundation with a minimal batch-style Python agent so CI/CD and deployment wiring can be added before the full sender and receiver workflows are implemented.

The current foundation provides:

- a Python package using a `src/` layout
- environment-driven agent configuration
- a placeholder agent run loop with structured JSON logging
- unit tests for config loading and execution entrypoints
- a production container image build

## Runtime model

The agent is currently modeled as a job-oriented process.

Environment variables:

- `AGENT_MODE`: `sender` or `receiver`
- `TENANT`: defaults to `tts`
- `ENVIRONMENT`: defaults to `development`
- `AWS_REGION`: defaults to `us-east-1`
- `LOG_LEVEL`: defaults to `INFO`
- `TRANSFER_SESSION_ID`: optional; autogenerated if omitted

## Local development

Create a virtual environment and install the package with test dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .[test]
```

Run the agent:

```bash
python -m redwood_dataagent
```

Run tests:

```bash
pytest
```
