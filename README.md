# ttse-redwood

Repository for the TTSE Redwood Data Agent.

This repo is the application container for the Federal Data Exchange MVP described in [003-mvp-architecture.md](https://github.com/GSA-TTS/TTSE-Redwood/blob/main/docs/adr/003-mvp-aws-infrastructure-diagram.md).

## Current scope

The repository provides an MVP foundation for the Day 1 sender-to-receiver transfer workflow:

- Python package using a `src/` layout
- Environment-driven agent configuration with dynamic sender/receiver agencies
- Sender workflow: file scanning → policy check → compression → manifest generation → S3 staging
- Receiver workflow: landing validation → decompression → target storage
- SFTP client integration for future transfer operations
- Structured JSON logging and audit events with `transfer_session_id` correlation
- In-container 5-minute polling for new files (S3 event-driven triggering deferred to future phase)
- Comprehensive unit tests and container build

## Runtime model

The agent is currently modeled as a job-oriented process.

Environment variables:

- `AGENT_MODE`: `sender` or `receiver`
- `TENANT`: defaults to `tts`
- `ENVIRONMENT`: defaults to `development`
- `AWS_REGION`: defaults to `us-east-1`
- `LOG_LEVEL`: defaults to `INFO`
- `TRANSFER_SESSION_ID`: optional; autogenerated if omitted
- `SENDER_DATA_DIRECTORY`: S3 directory path scanned for incoming files (e.g. `s3://bucket/incoming/`); required for sender-mode runs

## Local development

Create a virtual environment and install the package with test dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[test]'
```

Run the agent:

```bash
python -m redwood_dataagent
```

Run tests:

```bash
pytest
```
