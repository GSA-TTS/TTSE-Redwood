# TTSE Data Adapter

This repository contains the TTSE Federal Data Exchange (FDE) adapter implementation and supporting design artifacts.

The repository is intentionally bootstrapped with a minimal structure; implementation details will evolve via ADRs.

## Repository Structure

- `docs/adr/`
  - Architecture Decision Records (ADRs)
- `src/`
  - Application source code
- `tests/`
  - Unit/integration tests

## ADRs

Architecture decisions should be captured as ADRs in `docs/adr/` to document:

- tradeoffs considered
- decisions made
- rationale and implications

## Development

Development setup, runtime, and tooling will be documented once the initial implementation approach is selected.

## Contributing

- Use small, reviewable pull requests.
- Keep changes aligned with ADR decisions.
