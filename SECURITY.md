# Security Policy

## Supported Versions

We actively support security updates for the `main` branch.

| Version | Supported |
| ------- | --------- |
| main    | ✅ Yes     |
| older branches | ❌ No |

## Reporting a Vulnerability

Please **do not open a public GitHub Issue** for security vulnerabilities.

Instead, report security concerns privately using one of the following methods:

### Preferred: GitHub Private Vulnerability Reporting

1. Go to the repository.
2. Click on the **Issues** tab.
3. Select **New issue**.
4. Create a new issue and create a relative security issue.

This ensures the report is private and visible only to maintainers.

### Alternative: Email

If you have trouble creating Issues, contact the maintainers directly:

`heman.malik@gsa.gov`, `siva.paydiparthi@gsa.gov`

## What to Include in Your Report

Please provide:

- A clear description of the vulnerability
- Steps to reproduce (if applicable)
- Impact and potential risk
- Affected branch/commit/version
- Any suggested mitigation or fix
- Your contact information (optional)

## Response Process

- We will acknowledge your report promptly.
- We will investigate and provide updates as appropriate.
- We follow responsible disclosure practices and may coordinate public disclosure after a fix is released.

## Security Updates

Security fixes will be released through normal repository updates and documented in release notes where applicable.
