# Dataproduct Examples

This directory contains committed, sanitized examples used for onboarding and documentation.

## Structure

- `definitions/*.json`: sample `DataproductDefinition` payloads.
- `requests/*.json`: sample `DataproductRequest` payloads.

## Guidelines

- Keep examples free of secrets and environment-specific endpoints.
- Use placeholder emails, IDs, and synthetic values only.
- Keep examples aligned with schema changes in `../schema/`.
- Authoritative contract schemas are maintained in `../schema/`.
